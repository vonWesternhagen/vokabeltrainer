Neue Vokabeln additiv einlesen

Dieser Import fügt nur neue Vokabeln hinzu. Bereits vorhandene IDs werden nicht verändert. Damit bleiben manuelle Korrekturen und Verschiebungen erhalten. Lernstände werden hier niemals importiert oder überschrieben.

Komplettes Backup

Ein vollständiges Backup enthält Vokabeln, Lernstände in beiden Richtungen, Klassenarbeitsplanung und Einstellungen. Wiederherstellen ersetzt den aktuellen lokalen Datenbestand vollständig.

NAS / Gerätewechsel:
Das komplette Backup kann über die Dateien-App auf FRITZ!NAS gespeichert werden. Auf einem anderen Gerät wird es ausschließlich über „Backup wiederherstellen“ eingelesen. Eine reine Vokabeldatei gehört dagegen immer in den additiven Import oben.
