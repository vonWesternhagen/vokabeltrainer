JSON-Import ist additiv: neue Vokabeln werden ergänzt. Bei gleicher ID werden Texte aktualisiert, der Lernstand bleibt erhalten. Eine zweite Sprache kann über eine zweite JSON-Datei mit eigener course.id importiert werden.
